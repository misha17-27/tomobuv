# Tomobuv — оптовый интернет-магазин обуви

Новый сайт [tomobuv.com.ua](https://tomobuv.com.ua) на чистом PHP 8 — замена Webasyst.
Быстрый на обычном хостинге при каталоге 100 000+ товаров, все адреса и SEO-мета старого сайта сохранены.

- **Витрина**: каталог с фильтрами и табличным видом для оптовиков, товар (цена за пару и за ящик, заказ ящиками),
  корзина и оформление в один шаг, «купить в 1 клик», избранное, сравнение, кабинет с историей заказов,
  бренды, поиск с подсказками, блог, инфо-страницы, отзывы, мультивалютность (UAH/USD/EUR).
- **Админка** `/admin/`: заказы, клиенты, заявки, товары с фото и характеристиками, категории, бренды,
  импорт прайсов поставщиков (CSV/XLSX/XML/YML) и экспорт, страницы, блог, баннеры, редиректы, настройки и SEO-шаблоны.
- **Перенос** со старого сайта одной командой: товары, фото (те же адреса), категории, бренды, клиенты с паролями, заказы.

Документация: [docs/INSTALL.md](docs/INSTALL.md) — установка и переезд, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — устройство и правила разработки.

Быстрый старт локально:

```bash
cp config/config.example.php config/config.php   # заполнить доступ к БД
php bin/install.php && php bin/import-webasyst.php && php bin/i18n-seed-uk.php
php bin/create-admin.php you@mail.com Пароль123 admin
php -S localhost:8080 -t public public/router.php
```
